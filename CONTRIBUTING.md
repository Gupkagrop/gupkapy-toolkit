# Руководство по участию в разработке (Contributing Guide)

Благодарим за интерес к развитию проекта `pocket-toolkit`!

## Основные принципы библиотеки

1. **Zero Runtime Dependencies** — библиотека не использует внешних зависимостей времени выполнения, опираясь исключительно на стандартную библиотеку Python $\ge 3.12$.
2. **Строгая типизация (Strict Typing)** — запрещено использование неявных типов и `Any`. Все интерфейсы, параметры функций и возвращаемые значения типизируются явно, включая Generics (`TypeVar`, `Generic`).
3. **Русскоязычные комментарии и docstrings** — все внутренние комментарии, документация к функциям и модулям пишутся на русском языке. Идентификаторы в коде (переменные, классы, методы) — строго на английском.
4. **Плоский поток выполнения (Early Returns)** — глубина вложенности не должна превышать 3 уровней.
5. **Принцип единственной ответственности** — функции должны быть сфокусированными (до 30–40 строк кода).

## Локальная разработка

### 1. Подготовка окружения
Проект управляется пакетным менеджером [uv](https://docs.astral.sh/uv/):

```bash
# Клонирование репозитория
git clone https://github.com/Gupkagrop/important-project.git
cd important-project

# Синхронизация зависимостей разработки
uv sync
```

### 2. Запуск тестов
Каждая функциональность должна быть покрыта тестами с проверкой крайних случаев:

```bash
uv run pytest
```

### 3. Проверка качества кода
Перед коммитом убедитесь, что линтер `ruff` не находит ошибок:

```bash
uv run ruff check .
```

## Стандарт оформления коммитов

Коммиты оформляются по стандарту Conventional Commits с описанием **строго на русском языке**:

* `feat(scope): описание новой функциональности`
* `fix(scope): исправление ошибки`
* `docs(scope): обновление документации`
* `test(scope): добавление или исправление тестов`
* `chore(scope): служебные задачи, настройки сборки`
